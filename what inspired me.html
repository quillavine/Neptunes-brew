Hi! I'm Percy. I found my love for coding after I was introduced to Boba on Slack.What really inspired me to make a website based on greek mythology and boba was a book. A book named Percy Jackson. When I first finished the tutorial for boba.html I was torn between what my website should be based upon. I started to browse through others websites for inspiration. I found 1 thing common in all of them. Did you guess it? It was the fact that every website was centered around that persons interests. Favourite hobby? Bam, their website was cooked on that basis. So while going through all of this I looked around my table for inspiration. Lo and behold, I saw the first ever book I read, Percy Jackson and the lightning thief. It is/was/and will be my most favourite book of all time. Sure, making a website is hard, but if you plan it efficiently I kid you not you will never be more proud of yourself.

⋆⭒ ̊.⋆The Learning Phase⋆⭒ ̊.⋆

I had previously learnt a bit about html from my school syllabus so i knew all the basics. I got bored of making the same type of basic apps using basic codes so I learnt more in depth about HTML and CSS. HTML stands for Hypertext Markup Language and CSS stands for Cascading Style Sheets. To put it in simple terms, HTML is like a skeleton, the basis of a website, and CSS is like an outfit, the element which adds pizzaz to the website. So basically, a skeleton without its outfit looks bare whereas an outit without a skeleton has no structure. Therefore, you need both (while its not absolutely necessary) to make a website that is both functional and visually appealing.

My website merely focuses on the way Greek Gods used to communicate in the past. I've not entirely copied the way the gods spoke because my boba website is based upon ambrosia meeting mortality.
